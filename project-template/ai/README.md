# ai/

Agent territory. The user should not have to work in here.

| Folder | Contents |
|---|---|
| `memory/` | Project memory. Read `MEMORY.md` first; write one fact per file |
| `tests/` | Tests the agent writes for the project's scripts and helpers |
| `review/` | Review notes, audit output, and change proposals |

Keep it small. These files are read into context often, and a bloated `ai/` folder costs
something on every task.
