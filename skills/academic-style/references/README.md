# Reference material for `academic-style`

Load one of these only when the task needs it. The rules an agent must never get wrong are in
[`../SKILL.md`](../SKILL.md); these files hold the depth behind them.

| File | Covers |
|---|---|
| [`imrad.md`](imrad.md) | Title, keywords, abstract, and each IMRaD section; the order to write them in |
| [`sentences.md`](sentences.md) | Sentence length, voice, transitions, what to cut, grammar policy |
| [`distinctions.md`](distinctions.md) | Terms that must not be blurred |
| [`citations.md`](citations.md) | Verifying, citing, and listing sources |
| [`figures-tables.md`](figures-tables.md) | Choosing, building, captioning, and referring to floats |
| [`ecology-fisheries.md`](ecology-fisheries.md) | Species names, stocks, surveys, effort, units |
| [`ai-disclosure.md`](ai-disclosure.md) | The ICMJE rules and the disclosure paragraph |
| [`checklists.md`](checklists.md) | Draft assessment and the pre-submission error sweep |

## Sources

The material is distilled from a graduate scientific-writing course (M. Jobling, UiT The
Arctic University of Norway, 2012), the
[ICMJE Recommendations](https://www.icmje.org/icmje-recommendations.pdf), the
[ICES Journal of Marine Science author instructions](https://academic.oup.com/icesjms/pages/General_Instructions),
and a document-grounded style analysis by Mikko Vihtakari.
